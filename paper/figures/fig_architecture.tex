% figure needs more room, MOVE NODES CLOSER or cut content -- do not add \resizebox back.
%
% STYLE. IEEE conventions: rectangular grouping, one arrow weight for normal flow, academic

\caption{Orbit-Evidence architecture. A learning-assisted satellite experiment acts from state
available at the decision instant $t_d$, freezes row and model state before deployment, and closes
retrospective labels later. Four executable validity layers run alongside it. Most rules inspect a
single execution; relational rules compare executions or aggregation levels. Applicable checks
resolve to \textsc{pass} or \textsc{halt}, while statistically unsupported decisions return
\textsc{indeterminate} rather than \textsc{pass}. Red dashed paths are prohibited and each is
\emph{chronologically consistent}, so an ordering check cannot express it; the blue dotted path is
one of the two classes ordering does catch.}
\label{fig:contract}
